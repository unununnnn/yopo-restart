# 票 07d safe_radius 对照

修法 1 是可选开关，不是新的默认。`policy_params.upstream.safe_radius` 或 CLI `--safe-radius`。缺省 0.05 m，与上游 d5e1e60 的 `safe_radius` 相同，解码器仍是 `UPSTREAM_DECODER`。0.35 m（机体半径）才标「偏离上游」。

没有改 L0 跟踪。`PointMassLag` 仍是 kp 4、kd 3、tau 0.1 s、a_max 6。

无解次数只数走廊里一个候选都没准入的提案（`CORRIDOR_EMPTY_HOVER`）。crossing 在这之后若契约允许，会把记录码写成 `BRAKE_ONLY`（运动学刹车）。这不是上游的「按住上一条 PositionCommand」。差别写在 ADR 0006 (i)。邻机冲突后的 `CONFLICT_BRAKE` 不算进这一列。

跑法：`forest.seed=7`，飞行 seed 0–9，影子盾关，三档各 10 个 seed，半径 0.05 和 0.35 各一遍。0.05 的到达、撞树和净空与票 07b（影子盾开）一致。机间碰撞 60 次里是 0。

净空 = 机体中心到障碍表面的距离 − 0.35 m。撞树后仿真停在第一次碰撞。到达时间只含到达的 seed，括号里是最小–最大。
