# 票 13c 六机林带弹性槽位

判据未冻结 / report-only。碰撞数照实写。决定见 [ADR 0014](../adr/0014-elastic-slot-clearance-gate.md)。L0，策略仍是上游 YOPO，`safe_radius` 仍是 0.05 m，结果里「偏离上游」为否。动力学仍是场景卡上的 kp 4、kd 3、tau 0.1、a_max 6。没有改候选排序，也没有引入 CPLEX。不改 yopo-swarm。

净空 = 机体中心到障碍表面的距离 − body_radius（0.35 m）。场景卡哈希与 #18 相同：medium `128eb7412296bad460bc3503e922f5614c1b2b97175d659fe9f28e64373de587`，sparse `6931bead71b44239e2225be44004a2040b49de4f5ee9c1ccd010ecb1a18b4b69`。

前表是 #18（当前 `origin/main` 的穿林行为，默认半径就是 0.05 m）。后表是本分支重跑的六机 medium / sparse，seeds 0–9，影子盾开。

## 改了什么

只动六机穿林（`n ≥ 6` 且卡上有 `forest`）。三机和柱林仍是原来的槽位前瞻，不读树。

- 林带里槽位是软目标。侧向在槽位左右 `lateral_slack_m`（默认 2 m）内，并且一次横移不超过同一界，再剪到走廊 y。纵向只瞄到 `longitudinal_slack_m`（默认等于 `min_ahead_m`，5 m）里整段都过净空门的那一截，不追已经跑远的时刻表。能走的侧向优先贴槽位。
- 出林前 `exit_tighten_m`（默认 4 m）把松弛收到 0。收紧后的射线要是进了树，就放回界内松弛。出了林带（x ≥ 30 m）回到原来的刚性槽位前瞻。
- COMMIT 前对轨迹按 0.02 s 采样。中心到树的最小距离必须 ≥ `body_radius + clearance_margin_m`。margin 默认 0.15 m，场景卡 `task.clearance_margin_m` 可改。不够记 `CLEARANCE_SKIP`，这条多项式不进提案。这是 LSC「不可行走的走廊不进优化」的过滤。
- 六机轮转 1.5 s 长于承诺地平线 1.0 s 时，YOPO 前缀盖到 1.5 s，少飞末端急刹。急刹按计划契约 a_max=80 生成，动力学 a_max 仍是 6。
