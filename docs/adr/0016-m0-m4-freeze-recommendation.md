# M0–M4 判据冻结（frank 已拍板）

编号是 0016。frank 2026-11-10 批准冻结建议表的全部建议；M2 队形门用 6.0 m。已冻的指标写入场景卡 `criteria.frozen` 与 `criteria.gates`，失败时 `yopo_l0.batch` / `scripts/regress.sh` 退出非 0。只报数的项不挡退出码。[0008](0008-report-only-until-frozen.md) 仍然管那些还没冻的指标。

全表、出处、复现命令和偏离上游清单见 [票 11 冻结建议表](../results/11-freeze-recommendation.md)。建议表里的数字来自 main `8ee3ca1d11056b653c659acba311c5e19482b134`（票 13e）上的测量，不是编的。

## Context

[docs/SPEC.md](../SPEC.md)「判据建议值」写明：数值待 frank 冻结，冻结前只报数、不判过。建议列是：

- M0：10 个 seed 中达终点数、碰撞数（必须 0）、每次墙钟。
- M1/M2：队形误差（相对槽位）p95、最小机间距离、最小障碍距离、碰撞数（必须 0）、到达率。
- M4：同上 + 各故障注入档位下的到达率。

M3 在 SPEC 里程碑里是「一种变阵 + L1 抽检」，判据建议值没有单列，按到达、过渡期碰撞和队形误差一起报。

票 02 到票 11c、再加 13a–13e，结果表一直标「未冻结 / report-only」。11a / 11b / 11c 和 13a–13e 都已合入。票 11 收口交了冻结建议表。frank 2026-11-10 全部按建议批准，本 ADR 从 proposed 改为 accepted，并打开对应开关。

## Decision

frank 2026-11-10 批准全部建议；M2 队形门 6.0 m。到达率保持 100%，不留余量。

- **已冻结**（失败则批跑退出非 0）：
  - 碰撞数 = 0：M0 upstream、M1、M2 柱林和三机林 medium、M3 过渡期、M4 开阔区六档（进程内）、M4 六机林 medium / sparse。
  - 到达满格：M0 upstream 10/10，M1 3/3，M2 柱林 10/10，M2 三机林 medium 10/10，M3 10/10，M4 开阔区每档 1.000，M4 六机林两档 60/60。
  - M0 到达时间 ≤ 5.0 s（实测 4.26–4.28 s）。
  - 相对槽位的队形误差 p95：M1 / M3 ≤ 0.05 m（实测 0.027 / 0.025 m），M4 开阔区 ≤ 0.10 m（实测 0.066 m），M2 柱林和三机林 medium ≤ 6.0 m（实测最大 4.610 / 4.818 m；不用 5.0 m，林带最宽 seed 只剩 0.182 m 余量）。
  - 最小机间距离：M1 ≥ 1.50 m，M2 ≥ 2.00 m，M3 过渡期 ≥ 1.20 m，M4 开阔区 ≥ 2.50 m，M4 六机林 ≥ 0.70 m（碰撞线）。
  - M2 柱林最小障碍净空 ≥ 0.40 m。
- **继续只报数**（不挡退出码）：
  - 所有墙钟（随负载变；六机林带单次已经超过 60 s，不进套件）。
  - certified 对照（0/10 到达，见 [0010](0010-certified-env-unknown-reported.md)）。同一张 `g2-pillar` 卡只对 `upstream` 开门（`gate_policies`）。
  - 三机林 sparse / dense（dense 在 07d 是 1/10、9 次撞树；两档都没有在当前 main 重跑）。`crossing-forest` 只对 medium 开门（`gate_densities`）。
  - 三机林 medium 的数值净空（最紧 0.260 m，不够支撑 0.40 m 那道门）。
  - 六机林带的官方 p95 和相对 p95，以及数值净空（最紧 0.126 m）。官方 p95 在门控关掉后对着墙钟槽位，和 M1 不是一个口径；相对 p95 中位数 9.29 / 6.17 m，还高于 13b 写过的 5 m。
  - M4 的 ROS 2 全档矩阵（只有 drop 20%、seed 0 的一次对账）。`formation-6-open` 只对进程内形态开门（`gate_forms`）。ROS 2 全矩阵另开票。
  - M3 的 L1 抽检（票 09 已关闭，没有新方案对照）。M3 先按 L0 变阵冻。
  - 影子拒绝率（L0 上开盾时多为 1.000，那是记录，不是失败）。
  - 六机柱林（未测，不进套件）。
  - `--duration` 短于场景卡 `task.duration_s` 的前缀跑（短跑到不了终点，不套这些门）。

偏离上游的构造（`stop_at_goal` 1.5 m、编队 Delay Check 0.05 s、视界与计划 a_max=6、三机林进度门控、六机林带弹性槽位 / 净空门 / 自检口径 / 暂关进度门控）已经记在 0009、0011–0015。`safe_radius` 默认 0.05 m 不是偏离。本 ADR 不改这些决定。

## Consequences

- 已冻指标写在对应场景卡的 `criteria.gates`。批跑在这些指标上失败就退出 1，回归会红。不要为了过回归而放宽门槛；若实测掉到门槛以下，先查回归再决定要不要另开票改门。
- 满格到达的余量是 0。这是有意的：结果确定，放宽会把少一架的回归藏过去。
- 六机林带的队形误差还不能冻。先要决定用官方 p95 还是相对 p95，以及 5 m 够不够。重新打开林带进度门控之前，还要解决 ADR 0015 里按 min 爬行太慢的问题。
- M3 按 SPEC 仍缺一次新方案的 L1 抽检。本次只冻 L0 变阵，L1 对照仍只报数。
- M4 按 SPEC 仍是 ROS 2 形态。本次只冻进程内六档；ROS 2 全矩阵另开票，在那之前只报数。
