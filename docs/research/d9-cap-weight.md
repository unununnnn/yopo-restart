# 票 D9：限速与 g2 加权 5 种子确认（只报数）

report-only，偏离上游。限速（`policy_params.student.knot_speed_cap_mps`）和 g2 加权都只在 `scripts/distill/d9/cap_weight.py` 里打开，库默认不变（限速缺省为关，`StudentPolicy.DEFAULTS` 不变），判据不变。官方 `/workspace/yopo-teacher-data/d6b/train/student.pt` sha256 前后都是 `e4bd2116…`。数字在 [d9-cap-weight-runs.json](d9-cap-weight-runs.json)。

## 1. 结论

5 个训练种子下，D8 的两个正向信号都没有到「确认」的程度。符号检验在 5 个种子下最小双侧 p 是 0.0625，本票没有一项比较达到这个值。

- **限速 2.0 m/s（配对）**：开阔三机的配对差是 +20 / +10 / 0 / +10 / 0（每个种子满分 60）。没有一个种子变差，符号检验 3 正 0 负，p = 0.25。自助法均值 +8，95% 区间 [+2, +14]，不含 0。合计从 150/300 升到 190/300。g2 配对差是 +5 / +5 / 0 / 0 / −10，合计 15/50 → 15/50。D8 看到的 g2 改善没有复现：种子 4 打开限速后从 10/10 掉到 0/10。
- **限速 2.5 m/s（配对）**：本票唯一在开阔、g2、撞障三项上都没有负配对差的设置。
  - 开阔：+10 / +10 / 0 / 0 / 0，区间 [0, +8]，合计 170/300。
  - g2：+10 / +5 / 0 / 0 / 0，区间 [0, +7]，合计 15/50 → 30/50。
  - 撞障：−10 / −5 / 0 / 0 / 0，合计 35 → 20 场。
  - 但非零差只有 2 个种子，符号检验 p = 0.5。
- **限速 1.5 m/s**：开阔均值 +12，但有一个种子 −10；g2 有一个种子 −10。在加权权重上，1.5 使开阔变差：0 / 0 / −20 / −20 / −40，区间 [−28, −4]。这是本票唯一区间不含 0 的负效应。
- **g2 加权 ×4（重训，按训练种子对齐，不是严格配对）**：开阔差 +30 / −20 / +60 / −10 / 0，g2 差 0 / −5 / +10 / +10 / −10。两个方向各 2 个种子，p = 1.0，区间 [−12, +40] 和 [−6, +8]。不确认。
- **限速 2.0 + 加权**：相对加权，开阔是 +20 / 0 / −20 / −20 / 0，g2 是 0 / 0 / 0 / 0 / +5。相对对照或限速单开，都没有更好。
- 机间碰撞：40 次评估全部是 0。撞障全部发生在 g2，开阔三机没有撞障。

**哪个臂值得做缺省候选**：只推荐把「限速 2.5 m/s」作为下一票的缺省候选（候选对照臂），继续用更多种子或更多场景确认。理由有两条：它是唯一在开阔、g2、撞障三项上都没有负配对差的设置；它只在评估时生效，不用重训。不建议现在改库默认。限速 2.0 只对开阔有稳定的正配对差，对 g2 没有。加权和合并臂不推荐。

## 2. 做法

- 数据：D7 的 r3 数据（基础 3015 窗 + D7 r1–r3 重标注窗），与 D8 相同。
- 训练：D5b r4 FitConfig，只换 `seed`。ctrl（不加权）和 g2w（D7 的 g2 重标注窗损失 ×4）各训种子 0–4，每个从头训。种子 0–2 与 D8 逐位相同：留出 RMSE 一致，种子 0 的评估分组与 D8 一致。
- 评估：口径同 D8。开阔三机 seeds 0–9，g2 seeds 0–4，1.0 m 与 1.5 m；影子盾开，track_clearance 关，r4 接口。每份权重在限速关 / 1.5 / 2.0 / 2.5 m/s 下各评估一次。限速只在评估时打开，不重训，所以同一份权重的各个限速是严格配对。
- 四个主臂：对照 = ctrl·关，限速 = ctrl·2.0，加权 = g2w·关，合并 = g2w·2.0。
- 统计：以训练种子为单位。每个种子的指标是开阔到达架数（满分 60）、g2 到达架数（满分 10）、撞障场数（满分 30）。
  - 符号检验：双侧精确，差为 0 的种子去掉。
  - 自助法：对种子有放回重抽 20000 次，取均值的 95% 百分位区间。
  - L0 的评估种子几乎不改变结局，所以每个训练种子实际上是一个样本，n = 5。
- uav2 时刻：每场逐架记录首次进入 1.5 m 到达半径的时刻（StudentPolicy 的 `arrive_radius_m`，库默认），只报数。

## 4. 下一步建议

- 把限速 2.5 m/s 作为候选对照臂，在 ≥ 10 个训练种子或更多场景（例如 D6 全套场景）上配对确认。若区间仍不含负值，再考虑转成缺省。
- 限速 1.5 在加权权重上明显伤开阔，以后不再用 1.5。
- g2 加权的效应完全被训练噪声淹没。要继续的话，需要先把单次训练的方差降下来（更多 epoch、更大批或多个种子集成），否则 5 个种子判不出 ±10 的差。
- 开阔场「3 架都停在 0.05 m 内」的场数（表 3.1 最后一列）适合和到达率并列报告，它能区分「晚到」和「没到」。

## 6. 局限

- n = 5 个训练种子，符号检验最小 p 是 0.0625，本票的任何比较都不可能在 5% 水平上显著。区间是自助法百分位区间，n 小时偏窄。
- L0 评估种子几乎不改变结局，到达数只取 0 / 10 / 20 / 30 这几档。
- 加权和对照是不同的训练，按种子号对齐不是严格配对。
- 限速只在评估时截结点，实际速度峰值会超过上限：g2 最大速度中位数在 2.0 m/s 上限下是 1.73–2.37 m/s。
- 只用 D7 的 r3 数据和 D8 的 ×4 权重，没扫其他权重，没开全量 D6b。
