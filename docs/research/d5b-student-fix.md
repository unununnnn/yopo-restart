# D5b：学生闭环接口修正、DAgger 与改训练（report-only）

本票只报数。新选项全部默认关；不选时 `StudentPolicy` 与 D5 逐位相同，`student_fit` 默认训练与 D5 逐位相同。不改 `core/`、已冻门、`scenes/suite.txt`、`docs/tickets.md`、`README`、`yopo_l0/backend/`。权重和数据在仓库外 `/workspace/yopo-teacher-data/d5b/`，仓库只记 sha256。地图边长和障碍半径是假设，不是论文复现。

评测四个场景，seeds 0–9。表里每格是“到达架次/总架次，撞障场数，超时场数，最小障碍间隙 m”。最小间隙是到障碍表面的距离减机体半径 0.35 m，负数就是碰上了。

## 1. 结论

- 接口：没有坐标、单位、归一化错误。闭环飞丢是三处语义不一致造成的：偏航来源、位置头和速度头不自洽、加速度含义。修正后速度不再发散，但 D5 权重仍到不了。
- DAgger r1–r3 没有改善闭环，r3 四个场景全部撞障。留出 RMSE 和训练损失都在降，网络在碰撞前 0.5 s 的状态上也比 r0 更贴近 EGO 重标注。问题出在高度：教师重标注自己保留了竖直动量，学生飞在训练里没有的 1.5 m 高度，竖直速度一路累积，最后撞地或撞树顶。
- 改训练选了 (1) 低维动作 + (2) DART 扰动重标注 + (3) 安全加权：网络只管水平，高度按目标高度指数保持；训练只算 x/y 损失；DAgger 和 DART 窗口 ×4，近障窗口 ×3。结果见第 6 节。
- r4 到达：g2 柱子 0/10、开阔三机对向 20/30、开阔三机平行 30/30、密度 0.14 单机 0/10；r3 是 g2 柱子 0/10、开阔三机对向 0/30、开阔三机平行 0/30、密度 0.14 单机 0/10；只给 r3 换定高动作、不重训：g2 柱子 0/10、开阔三机对向 0/30、开阔三机平行 0/30、密度 0.14 单机 0/10。有障碍的两个场景（g2、密度 0.14）仍然全部擦碰，最小间隙在 −0.01 m 以内，是贴着障碍过去的。
- 教师本身在密集格不可靠（第 7 节）。密度 0.14 的三机格里，DART 重标注有 27/118 场 EGO-Swarm 自己的最小间隙小于 0；重标注只能靠净空过滤兜底。

## 2. 接口诊断（仓库外脚本，复制在 `scripts/distill/d5b/`）

- (a) 输入：闭环里重建的状态和邻机特征与训练张量最大差 0.0；深度平均绝对差 0.0015（归一化单位）；网络输出差不超过 5e-5 m（d000）。

## 5. DAgger 为什么没用（数字）

- 数据量：三轮重标注一共约 27.8k 个窗口（r1 13805、r2 2838、r3 11114），基础训练集 420340 个，约 6.6%，等权混入。r2 只有 66 个作业，因为 r1 学生几乎场场在 2 s 内撞上，能截的状态少。
- 重标注质量：EGO 从学生状态接手的速度误差中位数 0.009–0.016 m/s，接手没问题。净空过滤几乎没删窗口（r1 13995→13805，r3 11230→11114），但带障碍的重标注场里教师自己最小间隙小于 0 的有：r1 15/57、r2 4/29、r3 10/37。
- 损失在降：留出位置 RMSE r0 0.0580 → r3 0.0566，每轮训练损失单调下降（r3：0.00996 → 0.00564）。所以不是没学会监督目标。
- 碰撞时刻对比（`scripts/distill/d5b/diag_collide.py`，取 r3 碰撞前 0.5 s 的状态，用 EGO 重标注，比较 1.6 s 处位置误差）：open3 r0 1.77 m → r3 1.56 m，swap 2.79 → 0.68 m，density 0.64 → 0.31 m。r3 更像教师了。但教师在这些状态下自己也保持竖直动量：1.6 s 内高度变化 open3 −0.48 m、swap −0.67 m、density +0.61 m。
- 失败形态：r3 的碰撞全是竖直方向。open3 uav2 在 1.5 s 时 z 0.52 m、vz −3.14 m/s；swap z 0.54 m、vz −2.39；g2 z 0.57 m、vz −3.24；density 爬到 z 2.39 m、vz +2.32 撞树顶（树高 2.5 m）。r0 高度一直在 1.5 m 附近。
- 原因：教师数据全部飞在 1.0 m，评测场景飞 1.5 m，深度图里的地面线索在分布外；网络 z 头和 L0 一阶滞后叠加，竖直速度自己喂大，DAgger 标签又忠实地保留这个动量。r0→r1 只换了约 6% 的数据，闭环就从 open3 20/30、swap 29/30 变成全撞，说明闭环对重训非常敏感，单轮评测的好坏有很大偶然成分。
- 训练细节：`train_from_paths` 每攒约 8 个 batch 才洗一次，一个 batch 基本来自 1–2 场，DAgger 窗口很难真正混进梯度。r4 把它调成 64（新选项 `shuffle_batches`，默认仍是 8）。

## 6. 改训练：低维动作 + DART + 安全加权

训练选项（`FitConfig`，默认全关）：`planar`（位置、速度损失只算 x/y）、`near_weight` / `near_depth_m`（深度图最近有效深度 < 1.2 m 的窗口 ×3）、`shuffle_batches`；`train_from_paths(path_weights=...)` 给 DAgger 与 DART 窗口 ×4。`planar` 时按留出 x/y 位置 MSE 选最好的 epoch。

DART 数据（`scripts/distill/d5b/dart_jobs.py`）：从基础训练场的教师轨迹上随机取时刻，加扰动后交给 EGO-Swarm 从扰动状态接手：横向位置 σ 0.4 m，横向速度 σ 0.6 m/s，纵向速度 σ 0.3 m/s，偏航 σ 0.35 rad；起终点高度随机取 1.0 或 1.5 m。8 个格（d000/d014 × 单机/三机 × 平行/对向）各 60 场，共 480 个作业。

## 9. 局限

- 每个设置只训练一次、评测 10 个 seed；L0 噪声小，同一权重下各 seed 结果几乎一样，10 个 seed 不能代表重训方差。r0→r1 的翻转说明单次训练结论不稳。
- `hold_goal_z` 是人为规定的高度，不是网络学出来的；它只适合定高飞行的场景。
- 评测场景飞 1.5 m，教师基础数据全在 1.0 m，DART 只补了 1.5 m 的一部分扰动样本。
