## 怎么重跑

```bash
make venv
git rev-parse HEAD
.venv/bin/python scripts/e-c4-density-l0.py --check-cards
.venv/bin/python -u scripts/e-c4-density-l0.py --run --jobs 1 --no-resume --out docs/research/e-c4-density-l0-runs.json
.venv/bin/python -m pytest -q tests/test_e_c4_density_l0.py
```

`--check-cards` 核对六张飞行卡与净空规则，并核对三份几何文件的 sha256 仍是 E-C4 写下的值。不要改那三份几何文件。`--jobs` 必须是 1；跑三个一起时不要同时再开别的重活。墙钟会变。全关臂在同 seed 下，到达、碰撞、最小距离和仿真时长不该变。三个一起的后段按墙钟截断，轨迹可能变。
