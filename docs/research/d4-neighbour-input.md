# D4：学生干路加邻机输入（脚手架）

这张票只把邻机特征接进学生网络和教师转换。学生默认关，不进飞行环，也不保存一份可以飞的权重。D5 才允许接到闭环。D1 的几何回退和 D3 的三个回归头都在 main 上，默认关，本票不动飞行路径。不改 `docs/tickets.md`，不改 `README`，不改 `core/`，不改已冻门，不改 `scenes/suite.txt`。

## 1. 输入

邻机特征是最近 K 架在机体系的相对位置和相对速度。K 默认 3，落在本票要求的 2–3 范围内。这个 3 是本票为了 CPU 冒烟定的，不是论文参数。

| 量 | 形状 | 含义 |
|---|---|---|
| `neighbor_rel` | `(B, 3, 6)` | 每个槽位：相对位置 3，相对速度 3，单位米和 m/s |
| `neighbor_mask` | `(B, 3)` | 1 表示这个槽位有邻机，0 表示缺位 |

相对位置是 `R_yaw(yaw).T @ (p_j - p_i)`。相对速度是 `R_yaw(yaw).T @ (v_j - v_i)`。按相对位置的欧氏距离升序取最近 K 架；距离相同按下标升序。缺位补零，掩码为 0。单机记录三个槽位都是零。三机记录用两个槽位，第三个补零。六机记录只保留最近三架。

代码在 [yopo_l0/student.py](../../yopo_l0/student.py) 的 `pack_neighbor_features`。

## 2. 和总线的关系

特征用的是位置和速度，和 `yopo_l0.bus.MessageBus` 上能广播的量同类，不是 B 样条系数。飞行环里，上游策略在打开机间项时，会把已提交轨迹的采样放进既有的 `peer_plan` 载荷；几何回退也会在总线上发采样。那些载荷里能还原的，仍是位置这一类运动学量。

教师转换没有走总线，也没有模拟丢包、复制、时延或乱序。它按 `trajectory.npz` 里同一拍的同步里程计取值。这是假设：零时延、无丢包。总线故障下邻机特征会变成什么样，未知。

`record.json` 里的 `/broadcast_bspline` 没有写成网络输入。样条系数和当前里程计是不是同一条曲线，本票没有比。还没有收到广播时，教师侧本来就把 `broadcast` 记成未知。

## 3. 网络

`StudentConfig.enabled` 默认 `False`。`predict` 在关着的时候返回 `None`，不建网络，也不检查邻机形状。配置关着时，即使调用方把 `predict(..., enabled=True)` 传进来，也仍然返回 `None`。`forward` 在关着的时候直接拒绝。飞行环的 `runner`、`policy`、`crossing`、`run` 都不导入这个模块。

打开只发生在测试和 [train_smoke.py](../../scripts/distill/train_smoke.py) 里显式传入 `enabled=True` 的地方。库函数 `train_smoke` 自己的默认值仍是不训练。

干路在 D3 的深度和状态之外，加了一条邻机支路：

- 每个槽位：线性 6→32→64，再乘掩码。
- 沿 K 求和。三个槽位都缺位时，这条支路是全零。
- 与深度 64 维、状态 64 维拼成 192，再线性到 128，后面三个头不变。

缺位里即使写下垃圾数，乘掩码之后前向结果不变。这个行为有测试。

三个头仍是 `(B, 8, 3)` 的位置、`(B, 8, 3)` 的速度、`(B, 8)` 的相对偏航。损失权重、1.6 s 视界、24×40 深度，沿用 D3 为 CPU 冒烟定的数，不是 EGO-Swarm 论文里的数，也不是 YOPO 的格子。

## 4. 数据映射

转换在 [yopo_l0/distill.py](../../yopo_l0/distill.py)，命令行是 [teacher_to_tensors.py](../../scripts/distill/teacher_to_tensors.py)。张量模式从 `yopo-student-window/1` 升到 `yopo-student-window/2`，增加 `neighbor_rel`、`neighbor_mask` 和 `ego_index`。

多机记录按每一架自己的视点出窗口，不再拒绝。`max-windows` 按（时刻，视点）对均匀抽取。单机记录的窗口选择和 D3 相同：只有一个视点，邻机张量全是零。

| 教师字段 | 学生张量 |
|---|---|
| `trajectory.npz` 的本机 `position_m` / `velocity_mps` / `yaw_rad` | 未来 8 个时刻，插值到 0.2 s 的倍数，再变到当前机体坐标。偏航做相对角并卷到 (−π, π] |
| 同一拍的本机速度、加速度、`goal_m` | 状态 9 维：机体速度、机体加速度、目标在机体坐标里的相对位置 |
| 同一拍其它飞机的位置、速度 | 最近 K 架的机体系相对位置和相对速度，缺位补零加掩码 |
| `scene.json` + `geometry.json` | 深度现算。视场角用卡上的，分辨率仍是 24×40。噪声固定为 0。邻机不画进深度，只走邻机通道 |
| `record.json` 的 `metrics.success` | 只有 `true` 才出窗口。`false` 和 `null`（未知）都是空批次，退出码 2，不写文件 |
| `bsplines` | 不把系数写入张量 |

某一架的相邻偏航差超过 π 时，整条记录拒绝：线性插值会插到反方向。短于 1.6 s 的记录出 0 个窗口。

## 5. 可用的教师数据

数字沿用 [d2-teacher-data.md](d2-teacher-data.md) 和 [d3-multihead.md](d3-multihead.md)，成功定义没有改：到达，并且表面距离大于假设的机体半径 0.20 m，并且没有机间碰撞。

按机数：1 架 49/64，3 架 23/64，6 架 18/64。合计成功 90/192。

0.42 obs/m² 这一档：单机 9/16，三机 0/16，六机 0/16。论文最密的一档仍然没有成功的多机示范。

仓库里的种子 0 样本，成功的多机只有密度 0 的四条：`d000-n3-headon-s0`、`d000-n3-parallel-s0`、`d000-n6-headon-s0`、`d000-n6-parallel-s0`。这四条没有圆柱，最近表面是地面，大约 1 m。密度 0.14 及以上的种子 0 多机样本，按 D2 的定义都不是成功，不能当示范。其它种子上成功的多机轨迹不在 `data/teacher/sample/` 里。

**这套能当场转的多机样本，不够训练一个要躲障碍、又要躲邻机的学生。** 本票因此停在脚手架，不提交权重。

## 6. 冒烟

用 [d000-n3-headon-s0](../../data/teacher/sample/d000-n3-headon-s0/scene.json)。这是 D2 种子 0、密度 0、三机对向的成功记录。203 拍、约 20.2 s。按 1.6 s 窗口、三个视点，全部合法窗口是 561 个。冒烟不用这 561 个，只沿（时刻，视点）均匀抽 4 个。每个窗口的邻机掩码是 `[1, 1, 0]`。

CPU，torch 2.4.1+cpu，没有 GPU。种子 0，Adam，学习率 1e-2，200 步。测的是这 4 个窗口上的训练误差，没有留出集。

| 量 | 值 |
|---|---|
| 损失 | 0.417502 → 9.50899×10⁻⁹ |
| 位置 MSE | 6.42925×10⁻⁹ |
| 速度 MSE | 7.07384×10⁻⁹ |
| 偏航 MSE | 2.62256×10⁻⁸ |
| 判定 | 位置 MSE < 10⁻³，并且末损失 < 初损失的 1/10 |

这只说明网络能记住这一条空地图三机轨迹上的 4 个窗口。不能外推到有圆柱的密度，也不能外推到 0.42 的密图。空地图上学到的，主要是邻机相对运动，不是绕障。

测试在 [tests/test_d4_neighbour.py](../../tests/test_d4_neighbour.py)：默认关且带着邻机输入时 `predict` 仍返回 `None`、飞行环源文件不点学生的名、打包函数的形状和掩码、偏航 π/2 时机体坐标、六机只留最近三架、缺位垃圾数不影响前向、三机样本可转、以及上面这次过拟合。不需要 GPU，也不需要 192 场。D3 的单机夹具测试仍在 [tests/test_d3_student.py](../../tests/test_d3_student.py)，单机窗口的邻机张量全是零。

```bash
.venv/bin/python scripts/distill/teacher_to_tensors.py \
    --run data/teacher/sample/d000-n3-headon-s0 \
    --out /tmp/d000-n3-windows.npz \
    --max-windows 6
.venv/bin/python scripts/distill/train_smoke.py \
    --run data/teacher/sample/d000-n3-headon-s0
```

`teacher_to_tensors.py` 在成功窗口数为 0 时退出码 2。缺字段或对不齐时退出码 1。
